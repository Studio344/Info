Dual Subtitles プライバシーポリシー

1. 対象

本ポリシーは、Studio344 が提供する Google Chrome 拡張機能「Dual Subtitles」のバージョン 1.0.11 を対象とします。Studio344 のウェブサイトについては、サイトのプライバシーポリシーをご覧ください。本拡張機能は Cookie、Google Analytics、Google AdSense を使用しません。

2. 本拡張機能が参照する情報

Prime Video または Netflix の再生ページで、本拡張機能はサービスがプレイヤーに配信する字幕トラックの一覧、言語、種別、字幕 URL を参照します。字幕の配置や端末内翻訳のために、プレイヤーが表示している字幕本文も読み取ります。字幕の表示と翻訳に使うデータは、再生タブと拡張機能内で処理します。

3. データの収集と送信

字幕本文、視聴中のページの URL、視聴履歴は開発者や報告フォームに送信しません。作品名や設定を自動で開発者や第三者に送ることもありません。テレメトリー、分析 SDK、広告 SDK、アカウント機能、外部翻訳 API、リモート SDK は使用しません。

Pro のライセンス確認では、製品識別子、ライセンスキー、確認を有効化として数えるかどうかの情報を api.gumroad.com へ送信します。

キーを入力して確認を求めたときに行います。登録後は、メンバーシップの終了、支払いの失敗、返金を確認するため、24時間に1回まで自動で再確認します。拡張機能のタイマーや設定画面、ポップアップを開いたことがきっかけになります。動画ページを開いたことでは再確認は始まりません。

ライセンス確認には、字幕本文、視聴ページの URL、作品名など、視聴を識別する情報は含まれません。ライセンスキーを一度も入力していない場合、この確認通信は発生しません。

字幕ファイル自体は、各サービスが公開した字幕URLから取得します。取得できるのは、そのサービス自身の再生情報から発見した完全一致のURLのみで、発見していないURLはネットワークアクセスの前に拒否されます。

任意の不具合報告

再生タブで「字幕の不具合を報告」を開き、項目の取得を選ぶと、対応サービス、取得できた作品名とシーズン・話数、本編の再生位置、2つの字幕の言語と種類を報告に添えられます。拡張機能のバージョンと、ブラウザーの種類とメジャーバージョンも添えられます。設定画面から報告する場合に添えられるのは、拡張機能とブラウザーの情報だけです。項目はフォームを開く前に確認して外せます。事前入力なしでフォームを開くこともできます。

事前入力つきの Google フォームを開くと、選んだ情報がその時点で Google に渡ります。フォームを開いた後に送信せず閉じた場合も同じです。事前入力には、視聴ページの URL、作品 ID、字幕本文、アカウント情報、ライセンスキーは含まれません。拡張機能は取得した報告用の情報を永続保存しません。自由記入欄には個人情報や認証情報を入力しないでください。

送信した回答は非公開の Google スプレッドシートに保管します。開発者は、不具合の再現と改善のために送信された回答を確認します。新着報告の確認と分類には OpenAI Codex を利用します。報告内容は、この対応に必要な期間だけ保管します。

4. Chrome ウェブストア限定使用要件

本拡張機能は、字幕表示、字幕の選択と整形、端末内翻訳、およびそれらに関する任意の不具合報告への対応に必要な範囲でデータを使います。データの販売、広告、プロファイリング、信用評価には使いません。利用者データの取り扱いは、限定使用要件を含む Chrome ウェブストアの利用者データポリシーに従います。

5. 端末内への保存

本拡張機能は以下の情報を保存します。

  • 設定（chrome.storage.sync）: 選択した2つの字幕言語、行ごとの文字サイズと色、その文字サイズを動画の大きさに合わせるかどうか、表示位置、CCクリーニングの各設定。これらは利用者自身の Chrome プロファイルを通じて同期されます。開発者が読み取ることはできません。
  • ライセンス確認結果（chrome.storage.sync）: 入力されたライセンスキーと、その確認結果をオフラインで信頼できる期限。
  • ライセンスの再確認記録（chrome.storage.sync）: 登録したライセンスキーと、前回の自動確認を始めた時刻。失敗後やブラウザーの再起動後も、24時間内に同じ確認を繰り返さないために使います。キーを登録し直すか削除すると消去されます。
  • ライセンス終了の記録（chrome.storage.sync）: 保存されていたライセンスが有効でなくなったと Gumroad から返されたときの、その理由（メンバーシップの終了、支払いの失敗、返金）と日時。Pro が終わった理由をプランの欄でお伝えするために使います。ライセンスキーや決済情報は含みません。ライセンスを再び有効化するか、その表示を閉じると削除されます。
  • 無料枠の利用時間（chrome.storage.local）: 本拡張機能の字幕が実際に画面へ表示されていた秒数の、1日ごとの合計。端末外へ出ません。記録されるのは日付と秒数のみで、作品名・URL・時刻は含みません。
  • レビュー依頼の判定（chrome.storage.local）: 上下2行を作品収録の公式トラックから5分以上表示した日付を、最大3件。設定画面で一度だけレビューをお願いするかどうかの判断に使います。日付と秒数のみで、作品名・URLは含みません。端末外へ出ません。
  • レビュー依頼の状態（chrome.storage.local）: そのお願いを表示した回数と、今後表示しないかどうか。端末外へ出ません。実際にレビューが書かれたかどうかは記録されず、開発者にも分かりません。

字幕本文および再生のために取得した字幕キューは、そのタブのメモリ上に保持され、永続的な保存は行いません。

6. 端末内翻訳

選択された言語の公式字幕トラックが作品に存在しない場合、本拡張機能は Chrome 内蔵の Translator API を用いて、サービス自身の字幕を翻訳します。翻訳は Chrome を通じて端末上で実行され、字幕本文が外部の翻訳サービスへ送信されることはありません。初めて使用する言語の組み合わせでは、Chrome が言語モデルをダウンロードすることがあります。これは本拡張機能ではなく Chrome が Google に対して行う通信です。

7. DRM と再生

本拡張機能は、DRM、映像データ、再生権限の取得・復号・回避を行いません。各サービスの再生リクエストを改変することもありません。各サービスが自身のプレイヤーへ既に配信している字幕情報を読み取るだけです。

8. 権限

  • activeTab は、ポップアップを開いたときに、現在の対応再生タブの状態を確認し、設定を反映するために使います。不具合報告では、利用者が希望した場合だけ、同じタブから報告用の情報を取得します。
  • storage: 上記の設定、ライセンス確認結果、無料枠の利用時間を保存するため。
  • https://api.gumroad.com/* は、入力された Pro のライセンスキーを確認するために使います。登録済みキーの自動再確認は24時間に1回までです。
  • alarms: 数時間ごとに本拡張機能のサービスワーカーを起動し、保存されている Pro のライセンスを1日1回まで再確認するため。視聴とは無関係のタイマーで、ライセンスキーが入力されていない場合は、起動しても何もしません。
  • scripting は、ポップアップを開いたとき、現在の対応再生タブで字幕処理がまだ起動していない場合に、そのタブのメインフレームで字幕処理を開始するために使います。

コンテンツスクリプトは、対象となる Prime Video、Amazon Video、Netflix の HTTPS ページでのみ動作します。字幕配信 CDN への恒久的なホスト権限は要求しません。

9. 決済

Pro は Gumroad が販売し、請求するサブスクリプションです。決済やアカウントの情報は Gumroad のサイトで入力します。Gumroad のライセンス確認結果には、購入者のメールアドレス、注文や支払いに関する情報、国情報などが含まれる場合があります。拡張機能は確認の成否とサブスクリプションの利用資格の判定に必要な返金、支払い失敗、契約終了の状態だけを使います。その他の購入情報は使わず、保存や転送もしません。

10. 児童について

本拡張機能は児童を対象としていません。

11. 本ポリシーの変更

重要な変更を行う場合は、本ページを更新日とともに改訂し、同じ変更で本拡張機能のバージョンを更新します。

12. お問い合わせ

この通知や報告した情報の取り扱いについてのお問い合わせは、Dual Subtitles のサポートページにあるフォームをご利用ください。
